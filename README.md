# Language Exercises

Scratch exercises and experiments, one directory per language.

| Directory | Language | Contents |
|-----------|----------|----------|
| [`prolog/`](prolog/) | Prolog | `prolog_examples/` (interpreter, symbolic executor, FP and pattern examples), `ilp/` (inductive logic programming runs) |
| [`datalog/`](datalog/) | Datalog | Soufflé programs — basic blocks, dominance, reachability, loop detection |
| [`ocaml/`](ocaml/) | OCaml | Exercises, a dictionary implementation, symbolic expression rewriting |
| [`lean/`](lean/) | Lean 4 | FP exercises |
| [`dafny/`](dafny/) | Dafny | Pre/postconditions, loop invariants, functions, sequences |
| [`scala/`](scala/) | Scala 3 | `hello-world` sbt project |
| [`haskell/`](haskell/) | Haskell | `test.hs` |
| [`clojure/`](clojure/) | Clojure | Placeholder |
| [`gforth/`](gforth/) | Forth | Placeholder |

See each directory's own README, where present, for run instructions.
